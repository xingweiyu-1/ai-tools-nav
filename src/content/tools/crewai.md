CrewAI 是时下流行的多智能体编排框架，用「**团队**」的隐喻组织协作：每个 Agent 扮演一个角色（如「产品经理」「工程师」「测试」），通过定义任务与流程，让多个 AI 像团队一样分工完成复杂目标。

它的 API 简洁、上手快，同时与 LangChain 生态兼容，能复用大量现成工具。对想快速搭建「多角色协作工作流」的开发者，CrewAI 是极低门槛的入口。

**适合谁**：希望通过角色化方式快速搭建多智能体工作流、并复用现有工具生态的开发者。
