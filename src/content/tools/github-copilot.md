GitHub Copilot 是最早让「AI 结对编程」进入主流的产品。作为 IDE 插件，它提供行内补全、Chat 对话、终端建议与代码审查，覆盖面广，且在 VS Code 与 JetBrains 生态中打磨得最成熟。

Copilot 的独特优势在于 **GitHub 集成**：能从仓库 Issue、PR 中获取上下文，自动生成 PR 描述，甚至给出代码审查意见，把 AI 织入整个开发流程而非单个文件。它支持接入 Claude、GPT、Gemini 等多模型。

**适合谁**：重度使用 GitHub 与主流 IDE，希望获得开箱即用、零配置 AI 助手的团队与个人开发者。
