AutoGen 是 Microsoft 开源的 Agentic AI 框架，核心思路是让**多个 AI 智能体互相协作**来完成任务：一个 Agent 写代码，另一个 Agent 审查与执行，通过对话和事件驱动编排复杂工作流。

它提供跨语言的运行时、可观察性与记忆能力，适合从原型到生产的 Agent 应用开发。AutoGen 也是学术界与工业界研究多智能体的热门框架之一。

**适合谁**：希望构建多智能体协作应用的开发者与研究者，尤其是在 Microsoft 技术栈内工作的人。
