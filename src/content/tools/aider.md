Aider 是最早把「AI 结对编程」做进终端的开源工具之一。它的核心理念是：**AI 改动的每一步都纳入 git 版本管理**，你可以随时 diff、回退或接受，就像和一个懂 git 的搭档一起工作。

Aider 支持接入大量模型，包括云端 API 和本地模型（如通过 Ollama），让开源社区可以用任意模型获得一致的体验。它对大型代码库的编辑能力与模型无关，只要模型够强，就能跨文件完成重构。

**适合谁**：喜欢 git 工作流、注重可审计性与版本控制，希望自由选择模型（包括本地模型）的开发者。
