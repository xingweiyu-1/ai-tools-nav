Cline（原 Claude Dev）是 VS Code 中最受欢迎的开源自主编码智能体。与纯补全工具不同，Cline 是**任务型 Agent**：你给出目标，它在 IDE 里自主查看文件、编辑代码、运行命令、安装依赖，并汇报每一步进展。

它提供 Plan / Act 两种模式，让你在「让 AI 自由执行」与「先确认方案」之间自由切换；配合 MCP 与细粒度权限控制，既能放开手脚，又能守住安全底线。代码完全开源，可自审、可二次开发。

**适合谁**：想在现有 VS Code 工作流中获得开源、可审计的自主 Agent 能力的开发者。
