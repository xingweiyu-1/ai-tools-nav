Roo Code 是从 Cline 分叉出来的开源自主编码智能体，进一步强化了**可定制性**。它用「模式（Mode）」来组织 Agent 的行为：架构师模式负责规划、编码模式负责实现、调试模式负责定位问题，每个模式都可以自定义指令与上下文。

对于想精细控制 AI 工作流的团队，Roo Code 提供了近乎无限的自由度：可以定义自己的角色、命令与多 Agent 协作流程，并把团队规范固化进模式里。

**适合谁**：需要把团队开发规范注入 AI 工作流、追求高度定制化 Agent 行为的开发者与团队。
